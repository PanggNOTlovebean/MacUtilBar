# MacUtil · Bar

独立的原生 macOS 菜单栏图标管理应用，最低 macOS 14。用来管理屏幕右上角那排菜单栏图标：可以收起、分区、排序、搜索，也能找回被刘海挡住的图标。

当前阶段：**方案设计**。仓库里还没有代码，也没有可安装的构建。

- 技术方案：[docs/technical-design.md](docs/technical-design.md)
- UI 设计 spec：[docs/ui-spec.md](docs/ui-spec.md)
- 视觉稿：[docs/design/1.0.0/](docs/design/1.0.0/)

身份（定稿后不再修改）：显示名 `MacUtil · Bar`，可执行文件 `MacUtilBar`，Bundle ID `local.macutilbar.app`，URL scheme `macutilbar`，配置文件 `~/.config/macutilbar/config.toml`。
