## 应用包图标不显示：根因

| 运行方式 | 状态项是否获得窗口 |
|---|---|
| 包内，Bundle ID `local.macutilbar.app`（原 autosaveName） | 否 |
| 包内，同 ID，全新 autosaveName / 不设 autosaveName（最小探针） | 否 |
| 同一二进制，包外运行（无 Bundle ID） | 是（主图标 x=1229） |
| 同一包，仅改 Bundle ID | 是 |

结论：系统按 Bundle ID 拒绝显示本 App 的菜单栏图标，与代码无关。Control Center 存储受保护，未读取、未修改、未绕过；未更改产品 Bundle ID。需要用户在 系统设置 › 菜单栏 › 允许在菜单栏中显示 中处理；应用在此状态下暂停折叠并显示说明（[截图](1.1.0/blocked-bundle-icons-en-light.png)），再次打开 App 会进入设置。

## 代码审查修复（发布前）

独立审查发现并已修复：
1. 移动中仍可对同一图标再次发起移动 → 一次只允许一个移动，重试走内部路径，移动中整行禁用。
2. 搜索面板重复打开/Esc 关闭会使扫描计数失衡，导致每 2 秒全量 AX 扫描一直运行 → 面板以单一 `shown` 状态管理计数，Esc 经同一关闭路径。
3. AXPress 打开菜单时状态项在调用内运行菜单，超时后又补发真实点击把菜单关掉 → 只在元素确实不支持按下时才点击，且移到后台队列执行。
4. 移动时可能拿到展开前开始的扫描结果 → 扫描进行中的请求排入下一次扫描。
5. 身份使用 AXTitle，实时文字类图标身份不断变化；同描述的图标 ID 重复 → 不再使用标题，同 App 内重复加序号。
6. 重试前置条件失败时不结束移动、菜单栏停在全部显示；移动中快捷键/点击/URL 可收起 → 失败时报告并恢复；移动中只允许“全部显示”。
7. 快捷键录制：切走应用后全局热键一直未注册、两个录制框可同时录制、外部配置重载会重新注册热键、非美式键盘记录错键 → 单一录制状态、失焦即停止、录制中不注册热键、按物理键码记录。
8. 分隔符顺序异常时仍允许移动 → 禁止。
9. 搜索面板重开保留上次查询、可能没有焦点 → 每次打开重建视图。
