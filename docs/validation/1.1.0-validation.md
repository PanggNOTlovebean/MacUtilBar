## 应用包图标不显示：根因

| 运行方式 | 状态项是否获得窗口 |
|---|---|
| 包内，Bundle ID `local.macutilbar.app`（原 autosaveName） | 否 |
| 包内，同 ID，全新 autosaveName / 不设 autosaveName（最小探针） | 否 |
| 同一二进制，包外运行（无 Bundle ID） | 是（主图标 x=1229） |
| 同一包，仅改 Bundle ID | 是 |

结论：系统按 Bundle ID 拒绝显示本 App 的菜单栏图标，与代码无关。Control Center 存储受保护，未读取、未修改、未绕过；未更改产品 Bundle ID。需要用户在 系统设置 › 菜单栏 › 允许在菜单栏中显示 中处理；应用在此状态下暂停折叠并显示说明（[截图](1.1.0/blocked-bundle-icons-en-light.png)），再次打开 App 会进入设置。
