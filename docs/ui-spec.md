# MacUtil · Bar UI 设计 spec

版本：草案 v1（2026-11-15）　视觉稿：[docs/design/1.0.0/](design/1.0.0/)

## 0. 视觉方向

**以 MacUtil · Paste 和 MacUtil · Right 的当前界面为准**，不参考 MacUtils（mactool）的界面。

设置窗口的外壳照搬 Paste 1.6 已批准的“基本设置”页（`MacUtilPaste/docs/design/1.6.0/basic-settings-approved.png`）：
- 白色窗口背景（`windowBackgroundColor`）。顶部是 64pt 的 App 图标、粗体 App 名和一句话标语。下面是蓝色的下划线文字页签，下方一条全宽细分隔线。
- 每个分组用粗体黑色小标题（15pt semibold，同 Right 的 `SettingsTokens.titleFont`），**不使用卡片底色**。每行左边是 13pt 标签，右边是控件，行与行之间用 `separatorColor` 细线分隔，行高 44pt。
- 控件右对齐、等宽：快捷键录制框、下拉框、带单位的数字步进框；三选一用分段控件，选中段是浅蓝底配蓝字。
- 统计或说明文字用 12pt `secondaryLabelColor`，次要操作用描边按钮（例如“清理历史…”）。
- 底部通栏：“配置文件：~/.config/macutilbar/config.toml”，11pt 灰字。

列表和面板沿用 Paste 1.8.0 的“安静原生”风格（`MacUtilPaste/docs/design/1.8.0/quiet-native-demo.png`），以及 Right 的列表行（`MacUtilRight/Sources/MacUtilRight/SettingsTokens.swift`）：
- 列表行：22pt 彩色圆角图标块（`iconRadius` 6），标题 13pt，下面一行 12pt 灰色说明，控件在行尾。行高至少 38pt（Right）；在管理列表里用 44pt。
- 行尾操作用 Paste 的 ↑ ↓ ✎：无边框，悬停时出现浅灰底，点击区 36pt；到边界时变浅并禁用。
- 选择类面板：选中行是实心蓝底配白字，悬停是浅灰底；顶部搜索框自动获得焦点；底部用小号键帽提示快捷键（↩ 打开、⎋ 关闭）；右上角显示结果数。
- 强调色用系统蓝（`controlAccentColor`）。Bar 的品牌色只用在 App 图标上。
- 深色外观：沿用 Paste 1.8.0 的深色版本。

## 1. 菜单栏图标

### 1.1 主图标（`MacUtilBar.Main`）

- 与家族菜单栏模板图同一套规范（`MacUtilRight/docs/design/icons/menubar/*-template.svg`）：64×64 画布，黑色加透明，5pt 圆角描边，局部实心块，以 18pt 显示，由系统自动反色。
- 图形：一个横向圆角矩形，代表“菜单栏”；左侧是一个 `‹` 折线，右侧是两个实心小圆角块，代表“图标”。展开状态时 `‹` 换成 `›`。切换时做 120ms 淡入淡出。
- App 图标（Dock 和设置页头部）：家族风格的渐变圆角方块。Bar 的主色定为紫色 `#6A3FD6`（渐变从 `#A27BFF` 到 `#6A3FD6`），和 MacUtils 的蓝 `#2350E0`、Right 的橙 `#EE6417`、Paste 的绿 `#0F9468` 区分开。正式图标在图标画布里单独出稿。
- 角标：检测到刘海遮挡时，右上角显示一个 5pt 的实心圆点（模板色，不用红色）。隐藏机制失效时显示 `!` 小角标（§6）。
- VoiceOver 标签：“MacUtil Bar，已收起 5 个图标，按下以展开”或“……已展开，按下以收起”。

### 1.2 分隔符样式（设置里三选一，默认“箭头”）

| 样式 | 永久隐藏分隔符，展开时 | 收起时 |
|---|---|---|
| 箭头 | `‹‹` 12pt，50% 透明度 | 不可见（被撑开到屏幕外） |
| 竖线 | 1pt × 14pt 竖线，40% 透明度 | 同上 |
| 圆点 | 4pt 圆点，40% 透明度 | 同上 |

### 1.3 鼠标和键盘交互

| 操作 | 结果 |
|---|---|
| 左键点击主图标 | 在收起和展开之间切换 |
| ⌥ + 左键 | 全部展开（包括永久隐藏区）；再点一次全部收起 |
| 右键，或 ⌃ + 左键 | 弹出菜单（§2） |
| 悬停在菜单栏空白处 0.3 秒（需开启） | 展开；指针离开菜单栏后开始自动收起倒计时 |
| 在菜单栏上滚动（需开启） | 向下滚展开，向上滚收起 |
| ⌃⌥B（默认，可改） | 切换收起/展开 |
| ⌘ 拖动任意图标 | 系统原生的移动；放到主图标左边就进入隐藏区 |

## 2. 右键菜单

和 Paste 一样精简，只有一组，内容如下：

```
显示全部图标        ⌥ 点击
─────────────
设置…              ⌘,
退出 MacUtil Bar    ⌘Q
```

- “显示全部图标”切换全部展开；处于全部展开状态时，文字变成“收起全部图标”。
- 有异常时，在第一行上面插入一行提示，例如“⚠︎ 分隔符顺序异常，点击修复”或“⚠︎ 当前系统无法隐藏图标”，点击后去设置页的对应位置。
- 鼠标离开菜单和图标后自动关闭，规则与 Paste 1.6.5 相同：两者之间留短暂的过渡时间，鼠标移回来就取消关闭。

## 3. 设置窗口

- 外壳完全照 Paste：默认 680×600，最小 620×520，记住位置。窗口标题是 `MacUtil Bar`。
- 头部：64pt 的 App 图标、粗体标题“MacUtil Bar”、标语“菜单栏，只留需要的。”
- 页签：蓝色下划线文字页签，选中项宽度固定，切换时不跳动。
  - 1.0：**基本设置** · **布局**
  - 1.2：再加 **规则**
- 底部通栏：“配置文件：`~/.config/macutilbar/config.toml`”，点击在 Finder 中显示。

### 3.1 基本设置

分组用粗体小标题，行与行之间用细线分隔，没有卡片底色（同 Paste）。

**常规**
- 快捷键　[录制框 ⌃ ⌥ B]；冲突时，下面用 12pt 红字写“该快捷键已被其他应用占用”
- 界面语言　[简体中文 ⌄]
- 外观　[跟随系统｜浅色｜深色] 分段控件
- 开机启动　[开关]；需要在系统设置里批准时，下面显示一行灰字说明和“打开登录项设置”链接

**展开与收起**
- 悬停在菜单栏空白处展开　[开关]
- 悬停延迟　[0.3 ⇅] 秒（只在开启悬停时可用）
- 在菜单栏上滚动展开　[开关]
- 自动收起　[10 ⇅] 秒（0 = 不自动收起）
- 切换应用时收起　[开关]
- 说明行（12pt 灰）：“左键点击主图标始终可以展开或收起；⌥ 点击显示全部。”

**外观**
- 分隔符样式　[箭头｜竖线｜圆点] 分段控件
- 刘海遮挡提示　[开关]（只在有刘海的 Mac 上显示这一行）

### 3.2 布局（1.0，不需要权限）

**当前分区**（粗体小标题）
- 一条 36pt 高、仿菜单栏的横条：从左到右依次是“永久隐藏 ┆ 隐藏 ◉ 常显 ｜ 系统”，用浅灰的深浅区分，不用彩色底。每段下面用 12pt 灰字写图标数量（来自窗口坐标，不需要权限）。

**移动图标**（粗体小标题）
- 两行纯文字说明（13pt）：“按住 ⌘ 把图标拖到 ◉ 左边即可收起。” / “拖到 ┆ 左边则永久隐藏，⌥ 点击 ◉ 时才显示。”

**状态**（粗体小标题，没有状态时整组不显示）
- 刘海：“有 2 个图标被刘海挡住” + 右侧描边按钮 [展开查看]（临时全部展开 5 秒）
- 分隔符顺序异常：“分隔符顺序异常” + 右侧蓝色按钮 [一键修复]

**可视化排序**（粗体小标题）
- 一行：“识别每个图标并直接在这里调整，需要辅助功能权限。” + 右侧描边按钮 [启用…]。1.0 中禁用，按钮显示“即将推出”。

### 3.3 布局（1.1，已授权辅助功能）

当前分区的横条保留，下面换成图标列表，按“常显 / 隐藏 / 永久隐藏”三个粗体小标题分组。列表行用 Right 的 `SettingsListRow`，行尾按钮用 Paste 1.7.1 的显式 ↑ ↓。

每一行（44pt，行间用细线分隔）：
```
[App 图标 22pt]  名称（13pt）                    [常显｜隐藏｜永久]   ↑  ↓
                 Bundle ID 或 AX 描述（12pt 灰）
```
- 分区用分段控件（浅蓝底的选中段）切换，点击后立即移动图标。移动过程中行尾显示转圈；失败时行下方出现 12pt 红字说明和 [重试]。
- ↑ ↓ 每次移动一位，无边框，悬停时出现浅灰底，点击区 36pt，到边界时禁用。**不做拖拽排序**（Paste 1.7.1 的原则）。
- 没识别出来的图标显示灰色的通用图标，标题是“未识别的图标”，只能看，不能操作。
- 列表上方两行设置：自动恢复布局 [开关]；新出现的图标放到 [常显 ⌄]。

还没授权时，这个区域是普通的一组行：

> **需要辅助功能权限**（粗体小标题）
> 用来识别每个图标属于哪个 App，并替你按住 ⌘ 拖动它们。MacUtil Bar 不读取你输入的内容。　　[打开系统设置]
> 12pt 灰字：“授权后自动刷新，无需重启。”

### 3.4 规则（1.2）

- 列表的每一行是一条规则：“当 [Xcode 在前台] 时，[显示] [GitHub Desktop 图标]”，右边是开关和编辑铅笔（36pt 点击区）。
- 底部是 ＋/− 按钮。编辑在行内展开：条件选择器、动作选择器、目标图标选择器。
- 依赖辅助功能的动作，在没有授权时禁用，并说明原因。

### 3.5 图标间距（1.2，放在“外观”分组里）

- 图标间距　[滑块 4–16，默认 16]，旁边有一个实时示意图（三个灰色方块的间距跟着变）
- [应用…] 弹出确认框：“修改会写入系统全局偏好。之后打开的应用才会使用新的间距，已经在运行的应用需要重新打开，或者注销重新登录。” [取消] [应用]
- [恢复默认]

## 4. 搜索面板（1.1）

- 照 Paste 1.8.0 的历史选择框：屏幕居中，宽 560pt，圆角 12pt，白色（深色外观下为深色）。顶部搜索框自动获得焦点，占位文字是“搜索菜单栏图标…”，右上角显示“N 个图标”。
- 搜索框下方是蓝色下划线页签：全部 · 常显 · 隐藏 · 永久隐藏。
- 每行 36pt：App 图标（22pt），名称后面跟一段灰色的 AX 描述，匹配的关键词用黄色高亮（同 Paste）。选中是实心蓝底配白字，悬停是浅灰底。
- 底部用小号键帽提示：↩ 打开 · ⌥↩ 显示所在分区 · ⎋ 关闭。
- ↑ ↓ 选择，← → 切换页签（搜索框为空时），回车点开，Esc 关闭。
- 空状态：“没有找到图标”。没有辅助功能权限时，面板只显示权限卡。

## 5. 隐藏条（1.2）

- 位置：主图标正下方，距离菜单栏底部 4pt，右边沿和主图标右边沿对齐；空间不够时向左展开，不超出屏幕。
- 外观：高 32pt，圆角 10pt，系统菜单材质，带阴影。图标按菜单栏里的顺序排列，每个图标的点击区是 28×28pt。
- 没有录屏权限时，显示 App 图标（18pt）。悬停时出现 App 名称的系统 tooltip。
- 点击图标：隐藏条收起，对应图标的菜单从隐藏条的位置弹出。打不开时退回到临时展开菜单栏的方式。
- 鼠标移出隐藏条超过 0.5 秒，或者按 Esc，隐藏条关闭。
- 在刘海机型上，可以设置为“点击主图标时显示隐藏条，而不是展开菜单栏”（默认值：有刘海 = 隐藏条，无刘海 = 展开）。

## 6. 异常状态

| 状态 | 主图标 | 设置页 |
|---|---|---|
| 刘海遮挡 | 小圆点 | 布局页的状态区写明数量，并提供解决办法 |
| 分隔符顺序异常 | 无变化 | 黄色提示条 + [一键修复] |
| 隐藏机制失效（自检连续失败） | `!` 角标，点击后不再切换，而是弹出菜单 | 红色提示：“当前 macOS 版本暂不支持隐藏菜单栏图标”，并给出“打开 系统设置 › 菜单栏”的按钮 |
| 快捷键冲突 | 无变化 | 录制框下面显示红字 |
| 配置文件格式错误 | 无变化 | 页面顶部黄条：“配置文件有误，正在使用上次的有效设置” [在 Finder 中显示] |

## 8. 无障碍与键盘

- 设置窗口里的所有控件都能用 Tab 切换焦点，⌘1 / ⌘2 / ⌘3 切换页签。
- 布局列表的每一行都是一个 VoiceOver 元素，读法是“微信，隐藏区，第 2 个”；分段控件和移动按钮提供自定义操作。
- 遵守“减弱动态效果”设置：开启后，图标切换和面板弹出不做动画。
- 对比度：灰字在两种外观下都要达到 WCAG AA（4.5:1）。

## 9. 验收要点（UI）

- 每个页签在最小窗口 620×480 下，所有控件的尺寸都大于 0、文字完整（沿用 MacUtils 1.0.10 的教训：只检查控件有没有超出边界是不够的）。
- 中英文切换后，页签宽度不跳动，控件右边沿对齐。
- 深色和浅色外观下各截一张图存档，放到 `docs/validation/`。
- 菜单栏图标在深色、浅色和“降低透明度”三种情况下都清晰可辨。

## 10. 1.0.0 开发候选实现说明

- 最小内容区采用 620×520；基本设置用滚动区容纳完整选项。中英文、两种外观的原生视图快照归档在验证目录。
- 三状态项方案保留主图标左侧的窄空白 spacer，布局页文字明确图标应放到它左侧。
- 默认开机启动关闭，需用户主动开启；后续期功能只显示禁用的“即将推出”。
- 新增坐标不可用的降级状态：暂停折叠，展示“菜单栏当前不可用”及“重新检查”。候选版未完成 VM 与完整交互验收，不作为所有 UI 验收点已通过的声明。

### 1.0.1 降级提示

没有有效窗口位置时，分区数量显示“—”，说明尚未确认图标位置，提供“打开系统菜单栏设置”和“重新检查”。部分窗口在折叠后保持可见时，布局页显示剩余数量及系统指示器可能保持显示的说明；不显示“全部隐藏成功”。
