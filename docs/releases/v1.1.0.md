MacUtil · Bar 1.1.0 rebuilds Settings in the MacUtil family style and adds optional icon management.

- Settings: sidebar (Menu Bar Icons, Reveal & Collapse, Appearance, General), a toolbar switch for Collapse / Reveal / Show All, and problem notices at the top of every page.
- Optional Accessibility (requested only when you click Open System Settings…): see which app owns each icon, grouped into Visible / Hidden / Always Hidden; change an icon's section or order from Settings (MacUtil Bar ⌘-drags it for you and confirms the real position); a search panel (macutilbar://search or a shortcut you set) opens any icon's menu.
- Icon spacing: system-wide menu bar spacing with a live preview; applying and restoring both ask first and affect apps opened afterwards.
- Fixes: icons between the spacer and the MacUtil Bar icon are no longer counted as hidden; on a fresh install existing icons start in Hidden instead of Always Hidden; reopening the app opens Settings.

If MacUtil Bar's icon doesn't appear, open System Settings › Menu Bar › Allow in the Menu Bar, turn MacUtil Bar on (or off and on again), then click Check Again in Settings.

Not yet validated on a real Mac with Accessibility granted: icon identification, moving and the search panel. Hidden bar and conditional rules are not included.
