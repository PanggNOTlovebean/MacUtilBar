MacUtil · Bar 1.1.1 opens Settings whenever you launch it yourself (Finder, Spotlight, Launchpad, or opening it again while it runs), so you no longer need to go through the menu bar icon.

Launching at login, via a macutilbar:// link, or with --background stays quiet in the menu bar.

If MacUtil Bar's icon doesn't appear, open System Settings › Menu Bar › Allow in the Menu Bar, turn MacUtil Bar on (or off and on again), then click Check Again in Settings.
