MacUtil · Bar 1.1.2 fixes the settings window and menu bar icon flashing.

- The menu bar icon and the ‹‹ divider are only redrawn when something actually changes (previously every second).
- Settings no longer re-renders every second when nothing changed.
- The icon list no longer flashes: the per-row section switch no longer triggers SwiftUI layout cycles, the list only refreshes when an icon appears, disappears, is renamed or changes section, and app icons are cached.

If MacUtil Bar's icon doesn't appear, open System Settings › Menu Bar › Allow in the Menu Bar, turn MacUtil Bar on (or off and on again), then click Check Again in Settings.
